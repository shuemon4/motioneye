# Pi 4 Stream Debug Session - 20251223-1805

## Problem Statement
Video stream not displaying on Pi 4 (192.168.1.246). UI shows spinning loader instead of video feed.

## Evidence Collected

### 1. Screenshot Analysis
- UI shows "Camera1" configured
- Camera device: `camera0`
- Camera Type: `libcamera Camera`
- Resolution: 1280x720
- Frame rate slider at position 2
- Right panel shows spinning loader (no video)

### 2. Motion Endpoint Test

**CRITICAL: Motion is returning 0 bytes for the static JPEG endpoint**

## Key Finding: Stream Endpoint Issue

**Problem Identified**: MotionEye is trying to use `/1/mjpg/stream` endpoint, but Motion 5.0 doesn't provide this endpoint!

**Evidence**:
1. `main.js:5845` builds URL: `http://hostname:7999/1/mjpg/stream`
2. Testing shows:
   - `/1/stream` → Returns HTML (Motion webcontrol interface page)
   - `/1/mjpg/stream` → TIMEOUT (endpoint doesn't exist)
   - `/1/mjpg/static` → Returns 0 bytes (exists but broken)

**Camera Config Shows**:
- `streaming_direct_mode on` in camera-1.conf
- Frame rate = 2 fps
- Camera is working (Motion logs show motion detection events)
- libcamera is capturing frames

**Hypothesis**: Motion 5.0 changed the stream endpoint paths. Need to find correct endpoint.

## ROOT CAUSE CONFIRMED

**The Bug**: MotionEye uses WRONG endpoint path for Motion 5.0 streams

**Incorrect path** (current code): `/1/mjpg/stream`
**Correct path** (Motion 5.0): `/1/mjpg`

**Test Results**:
```bash
# WRONG - Times out, endpoint doesn't exist
curl 'http://localhost:7999/1/mjpg/stream'

# CORRECT - Returns multipart MJPEG stream (1.7MB in 3 seconds)
curl 'http://localhost:7999/1/mjpg'
```

**Stream Data Verification**:
- Content type: multipart boundary with JPEG images
- File size: 1.7MB in 3 seconds = ~566 KB/s
- Format: `--BoundaryString\r\nContent-type: image/jpeg\r\n...`

## The Fix

**File**: `motioneye/static/js/main.js`
**Line**: 5845
**Change**: Remove `/stream` from the URL path

```javascript
// BEFORE (incorrect)
var directUrl = 'http://' + window.location.hostname + ':' +
                this.config['streaming_port'] + '/1/mjpg/stream';

// AFTER (correct)
var directUrl = 'http://' + window.location.hostname + ':' +
                this.config['streaming_port'] + '/1/mjpg';
```
